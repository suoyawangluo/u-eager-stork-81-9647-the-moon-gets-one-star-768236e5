## The review

## How it works

`main.ts` (Node 22 standard library only) builds the review from its parts
and writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR` outside the
grader), then reads it back and verifies the gate: 1–120 characters, a single
non-blank line.

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
